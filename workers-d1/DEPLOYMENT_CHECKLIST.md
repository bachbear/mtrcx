# 部署检查清单

## 部署前检查

### 环境准备
- [ ] 已安装Wrangler CLI (`npm install -g wrangler`)
- [ ] 已登录Cloudflare账户 (`wrangler auth login`)
- [ ] 已验证账户权限 (`wrangler whoami`)

### 项目配置
- [ ] 检查 `wrangler.toml` 配置文件
- [ ] 确认项目名称和兼容性日期
- [ ] 验证D1数据库配置

### 数据库准备
- [ ] 创建D1数据库 (`wrangler d1 create subway-management-db`)
- [ ] 更新 `wrangler.toml` 中的 `database_id`
- [ ] 验证数据库连接

### 1. 数据库迁移
- [ ] 运行基础表结构迁移 (`0001_initial_schema.sql`)

- [ ] 验证数据完整性

### 2. Workers部署
